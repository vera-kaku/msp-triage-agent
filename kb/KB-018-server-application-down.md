title: A server or business application is down
queue: cloud-infrastructure

If a shared system such as a file server, accounting system or practice management application stops working for several people, call the service desk. This is treated as a priority incident.

To help us start straight away, tell us:
- which system is affected and the exact error message
- when it started
- how many people or sites are affected
- whether anything changed recently, such as an update or a power cut

Please do not restart shared servers yourself unless a technician asks you to. We will update you at least every hour until the system is back.
