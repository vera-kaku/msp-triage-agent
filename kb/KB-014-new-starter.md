title: Set up a new starter
queue: identity-access

---
Please send new starter requests at least three business days before the start date, and five business days if a new laptop is needed.

Include:
- full name, job title and start date
- manager's name
- which shared mailboxes, Teams and folders they need (see KB-005)
- whether they need a new laptop, phone or extra software licences

We create the account, assign the Microsoft 365 licence, set up the laptop and send the manager a temporary password and first-day instructions. If a laptop needs to be purchased, we will send a quote first (see KB-016). Requests with less notice are done as quickly as we can, but the laptop may not be ready on day one.
