title: Restore a deleted or overwritten file
queue: cloud-infrastructure
tags: [restore, deleted, recycle bin, version history, onedrive, sharepoint, backup, overwritten]
---
Files deleted from OneDrive or SharePoint go to the recycle bin first.

1. Open OneDrive or the SharePoint site in a browser.
2. Select Recycle bin, find the file and choose Restore.
3. If a file was overwritten rather than deleted, right-click it and choose Version history to restore an earlier version.

Items stay in the recycle bin for up to 93 days. If the file is not there, or it was stored on an office server, contact the service desk with the file name, its location and roughly when it was last correct. We can restore it from backup. Restores from backup are usually completed within one business day.
